# Pimou
marketplace enfant

## L'app mobile

Le code de l'app (Expo / React Native) est dans le dossier [`app/`](app/README.md).

```bash
cd app
npm install
npx expo start
```

Puis scanne le QR code avec l'app **Expo Go** sur ton téléphone (ou appuie sur `w` pour l'ouvrir dans le navigateur).

## Design

Le dossier `project/` et `chats/` contiennent la maquette Claude Design d'origine. Le fichier `DESIGN_HANDOFF.md` explique ce bundle.
